# My DevOps Environment Setup

This repository contains **my personal DevOps environment configuration** for both **macOS and Linux**.  
It’s the setup I use every day as a DevOps engineer, and it allows me to rebuild or migrate a workstation quickly without losing time reinstalling everything manually.

## ✨ What's inside
- **Dotfiles**: my custom shell, Git, tmux, and editor configurations (cross-platform).  
- **Package management**:  
  - macOS → Homebrew (`Brewfile`)  
  - Linux → package lists (`apt`, `dnf`, etc.)  
- **Setup scripts**: automatically detect the OS, install the right tools, and symlink configs.  
- **System preferences**: my tuned macOS defaults and Linux tweaks for productivity.  

## 🚀 Goal
This repo is my "single source of truth" for a complete DevOps workstation.  
Whether I’m setting up a new Mac or a Linux machine, I can bootstrap my environment in minutes and get back to work with the same tools, configs, and workflow.
